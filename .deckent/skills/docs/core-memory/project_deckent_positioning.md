**Deckent konumlandırma kararı (Alperen, 2026-06-02):**

1. **Tek-ürün MIT — KARAR VERİLDİ.** Open-core / Odoo-tarzı ayrı "Enterprise Edition" YOK. Tek MIT codebase; enterprise yetenekleri (multi-tenant, RBAC, SSO, mTLS, ERP, audit) modüler katman (`core` + `enterprise-layer`) ama **hepsi açık & ücretsiz**. ADR-033 (Product-Not-Service) KORUNUR. Bireysel kolaylık (native agentic REPL) + enterprise karmaşıklık AYNI üründe.

2. **"anti-X" dili KALDIRILDI.** Artık "the anti-Devin" gibi rakip-kötüleyen çerçeve KULLANILMAZ. Firmaları/araçları (Devin, Cursor, Claude Code, Cowork, Perplexity, açık agent CLI'lar) **kötülemeyiz — yetenek üzerinden kıyaslarız.** Saygılı karşılaştırma.

3. **Yeni konumlandırma (Alperen sözleriyle):** Deckent = "açık bir agent'ın **orkestre + enterprise + god-level** hali" ve **bu gücü bireysel kullanıcıya bile çok kolay sunmak.** Bir geliştiriciden 10.000-kişilik kuruma kadar tek MIT ürün. **Slogan: "Open source for open world."**

**Why:** Kullanıcı (a) gelir-kapısı/edition-split istemiyor — güç herkese açık olsun; (b) "anti-X" anlayışını mantıksız buluyor (kıyasla, kötüleme); (c) ana fark = enterprise-gücünü bireysele zahmetsiz sunmak.
