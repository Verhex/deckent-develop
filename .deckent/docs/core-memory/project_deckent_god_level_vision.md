> **Kapsam (2026-06-18 daraltıldı):** Bu memory yalnız **çalışma-kalitesi / işçilik disiplini**dir. Edition / community-enterprise / lisans / pozisyon konuları BURAYA KARIŞMAZ → [[project_community_pro_split_strategy]] + [[project_community_pro_split_strategy]].

**Tek kriter: düzgün işçilik, hep god-level.** Her iş ve yapı tam tasarımla yapılır; MVP / minimum / "şimdilik" iş veya yapı ÖNERİLMEZ. Tam-kapsamlı bakış açısı + düzenli iş mantığı her zaman hatırlanır. Kalite her seferinde kullanıcı promptuyla düzeltilmemeli — **ilk seferde doğru** olmalı.

### god-level çalışma prensipleri
1. **No MVP, no minimum** — her özellik tam tasarım, kısaltma yok ([[feedback_no_minimum_no_mvp_deckent]]).
2. **Tam-kapsamlı bakış** — dar/parça değil sistemin tamamı + iki-bakış (dogfood + product, [[feedback_dual_perspective_dogfood_product]]).
3. **Düzenli iş mantığı** — oku → planla → cerrahi-uygula → kanıtla; dağınık değil, sıralı ve izlenebilir ([[project_karpathy_skill_discipline]]).
4. **İşçilik = farklılaştırıcı** — milyonlara hitap eden ürün bilinci; teknik borç bırakma, i18n-temiz ([[feedback_god_level_i18n_quality_bar]]).

### YASAK pattern'ler
- "Bunu sonra ekleriz" → ✗ doğru abstraction şimdi
- "Minimum çalışır versiyon" → ✗ complete pattern
- "Hardcoded for now" → ✗ extensible default
- "TODO: optimize later" → ✗ Goal-Driven şimdi
- "Skip test for speed" → ✗ test first-class
- "Has tests ≠ works" → ✗ gerçek-davranış kanıtı ([[feedback_proof_of_function_dod]])
