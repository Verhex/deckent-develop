Alperen (2026-06-10): enterprise taraf çok gelişti → **modülerleşme + community/pro split**. **deckent community** (MIT, free) + **Enterprise sürüm ayrı** — modüler, community sürüme **lisansla doğrudan eklenebilir**. İsimlendirme örnek (`deckent` + `deckent-pro`), sonra kararlaştırılır. **⚠️ YAPI NETLEŞTİ (2026-06-11): AYNI kod tabanı + modüler eklenebilir `enterprise-layer` — ayrı ürün/fork/2-repo DEĞİL** ("böyle başladık böyle devam ederiz"). Community=MIT/ücretsiz (bireysel hiçbir şey paywall arkasında değil); enterprise-modül=FARKLI lisanslı (MIT değil), aynı repo'da lisansla etkinleşir. **ADR-033 ihlali DEĞİL** (gerekçe "iki kod tabanı/bölünme"ydi; tek-kod-tabanı korunuyor). Strateji: ürün geliri + danışmanlık geliri + community bilinirliği.

**Why:** Enterprise yüzeyin (RBAC/audit/tenant/SSO/SIEM/ERP) ticari değeri oluştu; gelir modeli + açık-kaynak bilinirlik dengesi.

**How to apply:**
- **SIRALAMA KESİN: EN SON değerlendirilir** — REPL/dashboard tam-işlevsellik + publish-readiness arc'ları bitmeden hiçbir sprint'e girmez. Sırası gelmeden modül-split işi planlama.
- O güne kadar yazılan kodda modül sınırlarını bilinçli koru (core ↔ enterprise-layer ayrımı zaten var) — split'i kolaylaştırır ama erken soyutlama yapma.
- **ADR-033 amendment YAPILDI (Sprint 281, 2026-06-11)** — artık "pending" değil: tek-kod-tabanı + modüler enterprise-layer + farklı-lisans, ihlal-değil olarak ADR-033'e + MASTER-PLAN §8'e işlendi. Sırası gelince kalan ön-işler: enterprise-layer dosya envanteri (temel: ADR-024/026 god-object split, ADR-008 import), lisans-yükleme mekanizması tasarımı, positioning revizyonu ([[project_community_pro_split_strategy]] o gün güncellenir).
- MASTER-PLAN §8 MOD-SPLIT + §10 "EN SON" satırı kayıtlı.

**📣 KONUMLANDIRMA (← `project_deckent_positioning` konsolide, 2026-06-30; MOD-SPLIT'in dış-yüzü; MASTER-PLAN §1 Positioning / §8 Comparison):**
- **Lisans çerçevesi:** tek kod tabanı — community=MIT (**TÜM feature**, bireysel hiçbir şey paywall arkasında değil), enterprise=AYNI feature + daha-derin governance/audit/management katmanı (FARKLI lisans → **derinlik, feature-gating DEĞİL**). Eski "tek-ürün MIT, edition-split yok" kararı (2026-06-02) GEÇERSİZ/tarihsel; sırası gelene dek dış-yüzey metinlerde erken duyuru YOK.
- **"anti-X" dili YASAK** (2026-06-02): rakipleri (Devin/Cursor/Claude Code/Cowork/Perplexity/açık agent CLI) kötüleme — yetenek üzerinden saygılı kıyaslama; tüm doc/pazarlama/ADR'de geçerli.
- **Slogan/çerçeve:** "Open source for open world" · **"Deckent: already orchestrated"** = agent/tool/provider/workflow/memory/governance/insan'ın ZATEN orkestre edildiği self-hosted işletim katmanı ("bir agent daha" değil, agent'ları çalıştıran düzen); açık-agent'ın orchestrate+enterprise+god-level halini bireysele bile zahmetsiz sun (tek geliştirici → 10.000-kişilik kurum).
- **Kategori:** Agentic-OS (kuzey-yıldızı) / bugün shipped: Orchestrator→Control-Plane; fark = 6 enterprise boyutu (Governance/Security/Process/Marketplace/Multi-tenancy/ERP) = enterprise-layer'ın kendisi. Ne çok-dar (coding-CLI'a sıkış) ne çok-geniş (erken OS-pazarlama) — vizyonu sahiplen, çekirdeği dürüstçe ship et. **Wedge:** local-first/air-gapped egemen orkestrasyon (KVKK/EU) + evrimsel memory/learning; yakın rakip AWS CAO + Hermes Agent + OpenClaw (Hermes = aktif analiz turu).
