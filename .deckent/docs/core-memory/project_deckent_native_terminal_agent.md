Loop+tool+izin+kimlik tamamen deckent'e ait.

**Transport:** Terminal yalnız **API veya yerel(Ollama)** ile çalışır (bunlar gerçek native tool_use verir; subscription raw API vermiyor). `deckent` yazılınca config'den API/local algılanır; yoksa "API veya yerel model bağla" + provider=local ama sistem algılayamadıysa dürüst hata.
