> **DURUM (2026-06-18): BEKLEMEDE — bu dogfood'a henüz başlanmadı.** Niyet geçerli; sırası gelince REPL/Ink + dashboard aktif-kullanım dogfood'u yapılacak.

Alperen (2026-06-10): "artık bir süre deckent'in kendi repl/ink terminalinde çalışmak, orada kullanmak istiyorum; ayrıca dashboard ve product taraflarını kullanarak oradaki tecrübeleri kontrol etmek istiyorum."

**Why:** Gerçek-kullanım (user-experience dogfood) — "wired ≠ kullanılabilir" dersinin ([[feedback_wiring_pct_vs_user_working]]) proaktif uygulaması; ürün yüzeylerinin kalitesi ancak günlük kullanımla doğrulanır.

**How to apply:**
- Alperen REPL/Ink + dashboard'da çalışırken çıkan UX bulguları birincil iş girdisidir — F11 kalanlarına (F11-012 UTF-8, F11-014 multi-provider parity, F11-016 Ink stabilizasyon) ve F7 dashboard control-plane'e akar.
- REPL/dashboard yüzeylerine dokunan işlerde proof-of-function çıtası daha da kritik (o yüzeyleri fiilen kullanıyor).
- MASTER-PLAN §6'da not var. Sıradaki sprint planlarında bu yüzeylerin pürüzlerine öncelik ver.
