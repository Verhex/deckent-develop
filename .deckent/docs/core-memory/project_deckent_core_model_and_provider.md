**Vizyon (Alperen, 2026-06-12):** deckent'in gücü = **localde paralel-agent orkestrasyonu** (sprint+task, yerel-modelle de çalışıyor — defalarca kanıtlı, basit prompt'tan agentic-OS). Bunun üstüne:

**Temel kat — Agentic Multi-Provider Mixed-Fleet (deckent'in çekirdek amacı, Alperen 2026-05-26/06-06):** 4 CLI — **Claude** (`@anthropic-ai/claude-code`) · **Codex** (`@openai/codex`) · **Gemini** (`@google/gemini-cli`) · **Cursor** (`cursor-agent`, post-beta) — **subscription-mode'da TEK sistemde aynı projede** koşar; API-key yalnız hacim-takviyesi (subscription=default, API=opt-in, [[project_api_mode_deferred_post_beta]]). TEK sprint'te provider/model EŞZAMANLI (örn. 1 Claude-subs + 3 Codex + 1 Gemini + 2 Ollama-local), seçim DIRECTIVES per-task (`- Provider:`/`- Model:`/`- Agent:`) **veya** Brain otomatik dağıtım; ilke **"doğru iş→doğru efor→doğru model→doğru provider"**, yerel Ollama filonun tam üyesi. **Neden:** WrongStack benchmark + agentic-OS milyon-user vizyonu; tek-CLI (Claude-only) = rate-limit + auth-loss riski; 4-CLI paralel rate-limit cap'i böler + her provider'ın gücünü kullanır. **WrongStack 3-Çatal Kararı (Alperen onaylı 2026-05-23):** ① provider-katalog = **models.dev her oturum live-fetch + 24h cache + fallback-cache** (`model-registry.ts` bootstrap kısmen wire) · ② vektör-arama post-GA Q3'26 (FTS5 Türkçe yeterli) · ③ runtime-dep status-quo (WrongStack 0-dep reddedildi). **Açık kalanlar:** Gemini subscription/OAuth-CLI (şu an API-key zorunlu → Codex-pattern'iyle düzeltilecek) · container `Dockerfile.worker` 3-CLI install (Codex/Gemini commented-out) + `DECKENT_OPENAI/GOOGLE_API_KEY` passthrough + 4-CLI tek-container `~/.claude`↔`~/.codex` mount-çakışması doğrula [[feedback_container_auth_precedence]] · mixed-fleet eşzamanlı-spawn canlı-doğrula (Ollama stub ✅ çözüldü ).

**1. Deckent Core (kendi fine-tune LLM'i):**
- Eğitim-verisi: deckent kullanım-profilleri + geçmiş kod-tecrübesi + **ilerledikçe ERP-enterprise süreçleri**. Model: süreç + deckent + agent-os + **tool-yönlendirmesi** öğrenir → orkestrasyon süreçlerini muazzam yönetir.
- subs+API tüm modellerle doğru çalışır (orkestratör tarafı). Deckent Core, terminal'in opsiyonel "daha iyi deneyim" base-agent'ı.
- Base aday: Qwen3 14B/32B veya Hermes-4-14B (zaten tool-trained) → QLoRA. Hermes dersi: **agent-trace-ağırlıklı dataset = sağlam tool-use** (model + vLLM tool-parser, tag-parse hack değil).

**2. Provider olma (Hermes/Nous playbook'u):** aynı fine-tune'u **vLLM ile sunucuda serve** (OpenAI-uyumlu `/v1/chat/completions` + tool-parser) + **API-key gateway** → deckent kendi kendine provider. 3-tier: BYO-key | yerel Ollama (deckent-qwen) | hosted Deckent Core. Sizing (doğrulanmış): 1×A100-80GB 14B ~1-3K tok/s aggregate (~20-50 eşzamanlı interaktif), yatay-ölçek lineer; RTX 5090 = dev/single-user.

**3. Kendi SDK + OpenRouter-mantığı:** çok-provider gateway/routing mantığı Hermes'ten kopyalanabilir; deckent'in kendi SDK'sı.

**4. Dağıtım:** ürün olarak local (github→npm install), kullanıcı localde yürütür; daha iyi deneyim için Deckent Core'u terminale bağlar.

**5. 🔴 Opt-in telemetri-feedback döngüsü (GİZLİLİK-KRİTİK):** her deckent projesine **kullanıcı-iznine tabi** ayar — anonim olarak ne-yapıyor/ne-tutuyor loglanıp belirli aralıklarla deckent endpoint'ine gönderilir (sprint-başarısızlıkları, dosya-sorunları...) → deckent gelişimi feedback'le devam. **Tasarım-zorunlulukları (CC notu, bağlamayıcı):** DEFAULT-OFF + açık-rıza (opt-in) + gerçek-anonimleştirme (PII/secret/kod-içerik sızdırma YOK) + şeffaf "ne gönderiliyor" görünürlüğü + air-gapped modda tamamen kapalı ([[project_air_gapped_offline_pillar]] + ADR-034 multi-project-isolation + mevcut telemetry_enabled/anonymous config ile uyumlu). Yanlış kurulursa güven-kırıcı — sessiz-toplama ASLA.

**Ölçek/yapı notu:** Bu çok-spec'li bir PROGRAM (tek spec değil). İlk somut spec = [[project_deckent_native_terminal_agent]] (terminal native-agent).
