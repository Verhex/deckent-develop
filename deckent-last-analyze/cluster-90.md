- [root-cause|low] `t()` last-resort renders the raw key string — `src/dashboard/src/i18n/LanguageProvider.tsx:44` — `let value = translations[lang][key] ?? translations.en[key] ?? key;`. - [root-cause|low] useSSE orders live overrides by lexical timestamp compare without format validation — `src/dashboard/src/hooks/useSSE.ts:66` `if (snapshotTs > override.ts)` and `:126` `if (snapshotTs > ts)` (with `:64`/`:125` defaulting a missing `lastHeartbeat` to `""`). The conflict rule "event wins iff its `ts` > agent's `lastHeartbeat`" trusts both strings to be chronologically-orderable UTC ISO-8601 (Z). A non-Z/offset or differently-formatted timestamp from either the snapshot or a `worker_heartbeat`/`worker_done` event would mis-order under string comparison and silently drop a fresh live override (or let a stale one win). trust-without-verify (no parse/validate before compare).

## Summary

18 files audited (7 ui primitives, 4 hooks, 4 i18n, 3 lib http). 17 findings, source-verified with file:line + snippet; no source modified (read-only audit).

- **unwired (2):** the whole `Table` family (table.tsx, 6 exports, 0 callers) and `useSheet` are dead — grep-confirmed zero consumers, no ui/ barrel masking it.
- **dormant (4):** `lib/api-client.ts` is a compat re-export with zero importers (the imports it claims to protect are all gone); the `Translator` base type, `useTabsContext`, and `buildChatStreamUrl` are exported but consumed only internally/by their own twin; two empty no-op prop interfaces (`SelectProps`, `TextareaProps`).
- **inconsistent (3):** two divergent same-named `useApi` hooks (hooks/ vs lib/, opposite shapes, both imported live); two divergent `?token=` query builders (string-concat vs URLSearchParams); a theme-token vs hardcoded-`zinc-*` split inside `ui/` while a Light theme toggle ships.
- **dead-test (2):** `live-merge.test.tsx` asserts useSSE source-text (`toContain`/`existsSync`) instead of behavior — green even on inverted merge logic; `chat-stream-client` is fully `vi.mock`'d in its only consumer test, so its real stream state machine is uncovered.
- **root-cause (4):** `useNervousStatus` silent hardcoded-0 hides a down endpoint as "0 pending" on the sidebar badge (highest-impact); LanguageProvider's double `.catch(()=>{})` swallows language load+persist failures (silent non-persist + revert); `fetchMe` collapses 401/403/500/network into one indistinguishable `null` identity; plus the `t()` raw-key fallback and useSSE's unvalidated ISO-string ordering as trust-without-verify tails.

Highest-leverage fixes: surface (not swallow) the nervous-status and language-persist errors, dedupe the two `useApi` hooks + the two token-query builders, and either delete `table.tsx`/`api-client.ts`/`useSheet` or wire them. The hardcoded-`zinc-*` ui primitives should migrate to the same semantic theme tokens their siblings already use, or the Light theme will render half-broken.
