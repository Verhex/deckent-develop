## Summary
This core#21 cluster mixes well-wired utilities (stack detection, skill selection/composition, sprint-file retention via `runRetention` in sprint-finalizer/cleanup, the `SprintSizeRecommendation`/skill-type factories) with a notable cluster of defined-but-not-honored surface. The standout is a security regression: the entire `spawn-safety` injection guard — advertised in its own header as the pre-spawn gate — is called by no production code, while real `spawnSync` sites in the same cluster bypass it, leaving the guarantee purely advisory (consistent with deckent's broader ADR-037 "advisory/soft enforcement" pattern). The recurring shape across the cluster is *validated/typed but never executed*: `promptInjection` knobs are validated yet ignored, `suggestSpawnBackend` types a `'tmux'` branch it cannot return, and `suggestMaxWorkers` exists in two divergent copies where only the host-detector copy reaches the live spawn path. The `'c#'` vs `'csharp'` key drift is a concrete correctness bug that mislabels C#/C/C++ project stacks. No test files were in this cluster's read scope, so the dead-test category is empty.
