### src/orchestra/heartbeat-daemon.ts
- [inconsistent|high] Shipped default heartbeat template contains a task its own validator hard-rejects — `src/orchestra/heartbeat-daemon.ts:36` — `DEFAULT_HEARTBEAT_TEMPLATE` line `- [ ] npx vitest run --reporter=verbose 2>&1 | tail -5` contains `|` and `&`; `SHELL_METACHAR_REGEX = /[;&|\`$()]/` (`:29`) makes `validateCommand` throw `COMMAND_INJECTION` (`:120-125`). The default task deckent writes for the user can NEVER execute — it is blocked the first time the daemon runs.
- [root-cause|medium] Hardcoded 5s exec timeout guarantees the default `tsc`/`vitest` tasks fail — `src/orchestra/heartbeat-daemon.ts:32` `const HEARTBEAT_EXEC_TIMEOUT = 5_000;` applied at `:176`; default task #1 `tsc --noEmit` (`:35`) on this codebase far exceeds 5s → `execSync` throws `ETIMEDOUT` → logged as ❌ (`:192`). The heartbeat's own seeded tasks fail by construction, producing a permanently-red `heartbeat-log.md`.
- [root-cause|low] Shell-string `execSync` instead of ADR-006 array-form `spawnSync` — `src/orchestra/heartbeat-daemon.ts:173` `output = execSync(task.command, …)` runs the command through `/bin/sh`; the only defense is the regex + whitelist in `validateCommand` (`:120-136`), not the no-shell array-form `spawnSync` pattern ADR-006 mandates and that the sibling `honest-gate.ts:337` actually uses.

## Summary
The cluster shows deckent's integrity/observability seams are plumbed but several are soft or dead: the honest-gate's git provider fails open (`honest-gate.ts:342-348`) and its `detectGarbageThrows` scanner is unwired, while the worker-question IPC is both never invoked (`askBrain`) and hardcoded to auto-`continue` (`ipc-registry.ts:234`) — three "guarantee" paths that exist on paper but do not constrain behavior. The most concrete latent defect is an ESM `__dirname` ReferenceError in `docs-config.ts:89` whose `catch {}` wrapper silently disables `deckent init` docs.json seeding, mirrored by the heartbeat daemon shipping a default task its own validator rejects (`heartbeat-daemon.ts:36`) plus a 5s timeout that dooms `tsc`/`vitest`. Documentation drift in the `orchestra/index.ts` barrel (claims cli/mcp/api consumers that import concrete files directly) and a missing NaN guard in the `test-coverage` doc generator round out a pattern of advisory-soft enforcement and silent-fallback masking real gaps.
