## Summary
orchestra#8 shows deckent's recurring pattern of **wired-but-soft guarantees**: cross-verify (default-OFF + advisory-only refutation), coverage-validator (trusts self-report when no vitest JSON, no `ERROR` level), and debt-manager (silent debt-skip with no DB, hardcoded-8 decay that the code itself flags as a known memory-loss regression) all degrade gracefully into no-ops rather than enforcing. A second cluster is **superseded-but-retained dead surface** — the entire `ConflictResolver` class and `buildCollisionAwareWaves` are test-only after plan-time `detectScopeCollisions` replaced them, and `DECAY_EXEMPT`/`HOST_PROJECT_DIR_TOKEN`/`rotateModelForFix` survive only via tautological tests or identity stubs. Finally there are two genuine correctness bugs hiding behind comments: the inverted NO_GO trend label and the `test_interference` dedup checking the wrong conflict type — plus a duplicate-divergent `CrossSprintAnalyzer` split across `orchestra/` and `agents/`.
