## Summary
This cluster's headline is **two whole dead modules in the dashboard `lib/`**. `terminal-sessions.ts` (the ADR-078 Part-D "god-level" multi-session manager: `MultiSessionManager` + per-session `CommandHistory` ring buffer + `SessionBuffer` + clipboard helpers) has **zero production callers** — the live `TerminalPanel.tsx` re-implements multi-tab tracking inline with `useState` and bypasses all of it; this deadness transitively kills `terminal-api.ts`'s `SessionRegistry`/`CommandHistory`/`SessionBuffer` (imported only by the dead manager + tests). `theme.ts` (a full dark/light JS design-token table) is likewise production-dead — real theming runs through Tailwind `@theme` vars + `ThemeProvider`'s `data-theme`, and `theme.ts`'s *only* consumer is `theme-consistency.test.ts`, a **tautological source-grep test** (`expect(readFileSync(theme.ts)).toContain("…")`) that asserts no behaviour and would pass against a string copy of the file — the canonical "dead module wearing a green check." A second, smaller dead-test of the same shape covers `MAX_LIVE_ACTIVITY` (`live-merge.test.tsx:90` `toContain("MAX_LIVE_ACTIVITY")`). The next theme is an **i18n split-brain**: `DebtPage.tsx` ships with NO `useTranslation` at all (every label hardcoded English) and `ChatPage.tsx` hardcodes Turkish slash-command descriptions — both escape the literal-label guard because that test scans only 3 of 17 pages and only sniffs for Turkish characters, so English-hardcoded DebtPage and out-of-list ChatPage both slip through. A **`useApi` name-collision** rounds out the structural risk: `lib/useApi` (`{get,post}`, 1 caller) and `hooks/useApi` (`{data,loading,error,refetch}`, 13 callers) share an identical name with incompatible contracts. The sharpest behavioural defect is `DashboardPage`'s **silent-swallow on destructive actions** — cleanup / kill-all / kill-worker all `catch { /* silent */ }`, so the dashboard's most dangerous buttons fail with no user feedback. Lower-severity drift: a dormant `label?` override field + a shadowed `navItems` derivation in `nav-items`/`Layout`, a misplaced SSE constant in `use-live-data`, a single-select `human_checkpoints` for a multi-phase setting, a redundant double `/api/status` fetch, an unused `postJson` import in ChatPage, and DebtPage re-parsing debt markdown client-side. Highest-value fixes: delete-or-wire `terminal-sessions.ts` + the three `terminal-api` classes + `theme.ts` (and the tautological tests that hide them); i18n-ize `DebtPage`/`ChatPage` and widen the literal-label test to all pages + English; collapse the two `useApi` hooks; and surface errors on the Dashboard's kill/cleanup buttons.
