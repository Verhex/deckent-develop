## Summary
This cluster is functionally live (all 12 page components are routed in `App.tsx:35-52` and render real API data), but carries a consistent layer of **drift, proxy-metrics, and aspirational-but-inert surface**. The highest-signal items: (1) **auth-source divergence in EnterprisePage** — the auth badge and all CRUD `mutate()` calls read the raw `window.__DECKENT_API_TOKEN__` global instead of the `useAuth` SSOT (`getBootstrapApiToken() ?? getSessionToken()`), so OIDC/manual-token users see "No auth token" and send unauthenticated mutations; (2) **WorkersPage "Worker Comms"** renders a surrogate (`doneAgents.length` + the DONE-agent list) as if it were real SharedMemory/handoff data — the doc-comment itself admits the "proxied" nature; (3) **routes.tsx** (`ROUTES`/`RoutePath`) is a zero-importer, stale 6-of-12 subset of the real route table whose only "tests" are source-text `toContain` greps; (4) **two stray build/test configs** — `src/dashboard/vitest.config.ts` (wired to no script, would mis-collect co-located tests and lacks happy-dom) and the committed `vite.config.d.ts` artifact; (5) **divergent duplicate type** — the dashboard's own `DeckentConfig` (zero importers, lags `core/types.ts`). Lower-severity but pervasive: an **i18n-FIRST regression** (EnterprisePage tab/header literals and a fully un-i18n'd MissionsPage), several **over-declared-but-unread interface fields** (EvolutionPage genealogy/stats/version fields, NervousPage `status`, MissionsPage `items`), and a **silently-dropped `data-testid`** on `<EmptyState>` that the hyphenated-attr TS exemption lets compile. No live source was modified (read-only audit); `npx tsc --noEmit` and `tsc --noEmit -p src/dashboard` both pass.
