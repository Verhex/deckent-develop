# mcp#5 — mcp (tools: skill-list/start/status/sync/usage/watch + writer-lease/writer-lease-gate)

Code-only audit, 8 files fully read. Each finding carries `file:line` + proving snippet. Zero-caller / dormant claims grep-verified against `src/` and `tests/`.

## Findings

### root-cause
- [root-cause|high] Writer-lease gate fails open for ALL write tools on fs-error — `src/mcp/writer-lease-gate.ts:64-72` — `} catch (err) { … return cb(args, extra); }` — On any lease fs-error the gate lets the write through. The comment justifies fail-open only for `deckent_start` ("backstopped by the deep sprint-lock"), but the code allows EVERY gated write tool (`deckent_config` set, `deckent_docs` write, `deckent_autonomous`, `deckent_nervous_config`, cleanup, etc.) — none of which have a deep-lock backstop. The single-writer guarantee is silently voided for the whole write surface on error. (advisory-soft)
- [root-cause|med] Corrupt lease file is treated as "free" → silent steal — `src/mcp/writer-lease.ts:63-65` + `:83-86` — `} catch { return null; }` then `if (existing === null) { writeLease(...); return { ok: true, ownerPid: process.pid, stolen: false }; }` — A malformed/garbage lease JSON is indistinguishable from "no lease": the live owner is silently displaced. "corrupt-as-free" is by design (header comment `:7`) but the corrupt-parse path emits no log/warn, so a real corruption-induced double-writer is invisible. (silent-fallback)
- [root-cause|med] Cost-gate failure silently lets the sprint start unbudgeted — `src/mcp/tools/start.ts:211-215` — `} catch (e) { … debugLog('start:costGate:error', e); }` — If `planSprint`/cost-config throws during pre-spawn estimation, the gate is skipped and the sprint proceeds. The "$42-overrun" class this gate exists to prevent (comment `:136-139`) is re-opened on any estimator error. (trust-without-verify / silent-fallback)
- [root-cause|med] Hardcoded token estimates drive the cost-gate verdict — `src/mcp/tools/start.ts:166-167` — `estimatedInputTokens: t.estimatedTokens ?? 2700, estimatedOutputTokens: t.effort === 'high' ? 4000 : t.effort === 'low' ? 500 : 1500` — When the planner does not supply `estimatedTokens`, the budget decision rests on magic per-task constants rather than measured/derived tokens. (hardcoded-metric feeding a gate)
- [root-cause|med] `failedTasks` hardcoded to 0 in rich status render — `src/mcp/tools/status.ts:455` — `failedTasks: 0,` — In explainatory/verbose/standart output modes the formatter is always fed 0 failed tasks regardless of actual NO_GO/failure count; the failed-task metric is a constant-0 on the rich status surface. (hardcoded-0-metric)
- [root-cause|low] watch falls back to bogus sprintId `'unknown'` — `src/mcp/tools/watch.ts:59` — `const resolvedSprintId = sprintId ?? getCurrentSprintId(root) ?? 'unknown';` — With no active sprint the tool subscribes/backfills literal sprint `unknown` (always empty) and reports "Subscribed to sprint unknown" instead of surfacing "no active sprint". (silent-fallback)

## Summary
- **unwired:** none. All six tool registrars are wired (`src/mcp/tools/index.ts:38,39,44,52,57,65`); `installWriterLeaseGate`/`installWriterLeaseReleaseHooks` wired in `src/mcp/server.ts:138,163`. `readWriterLease`/`releaseWriterLease`/`isProcessAlive`/`getUsageData`/`buildLeaseDenialResponse`/`isWriteCall` have zero external src callers but are genuinely used internally + by tests (test-only-exports, not unwired).
- **Highest risk:** `writer-lease-gate.ts:64-72` fail-open — on any lease fs-error the advisory single-writer gate opens for the entire write surface, while its safety argument only covers `deckent_start`. Paired with `writer-lease.ts` corrupt-as-free silent steal, the multi-IDE write-serialization guarantee is best-effort, not enforced.
- **Recurring root-cause theme:** soft/silent degradation on the error path (lease fail-open, corrupt-as-free, cost-gate catch→proceed) + hardcoded metrics feeding decisions/UI (`start.ts:166-167` cost tokens, `status.ts:455` failedTasks:0, `sync.ts:34` changeCount).
- **Test gaps:** sync and usage cost behavior are asserted only against mocks/empty-prices, so the two documented historical bugs (sync no-op semantics, Sprint-275 `$0` pricing) are not regression-guarded.
- 8/8 files read in full; report is read-only (no source modified).
