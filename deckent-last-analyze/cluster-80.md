### recall.ts
- [root-cause|medium] db-not-found prints an error but exits 0 (silent-success-on-error) — `src/cli/commands/recall.ts:26-29` (`if (!existsSync(dbPath)) { printError(getMessage('recall.db_not_found', lang)); return; }`). ## Summary
- **Headline (retro triplication).** `retro.ts` carries a verbatim inline copy of BOTH split-out modules (`retro-parser.ts`, `retro-formatter.ts`); the command imports neither, so the two extracted files are **unwired** (only their own tests load them) and must be maintained in parallel with the inline copy — a guaranteed-drift, triple-maintenance hazard.
- **Silent-success-on-error is the dominant root-cause pattern in the memory/read commands.** `recall.ts:26`, `remember.ts:23`, `resources.ts:189/197/225` all print an error and `return` with exit code 0 — divergent from `recover`/`run`/`serve`/`set-directives`, which set `process.exitCode = 1`. Scripts cannot detect these failures (continuation of the `memory.ts` cluster-79 finding).
- **`resume` does not actually resume what the user asked for** (`resume.ts:169`): no sprintId/resume-context reaches `runSprint`, which recovers off global `sprint-state.json` instead — and re-plans fresh when that file was cleared on a normal finish. Highest-severity behavioral bug in the cluster.
- **Dormant / no-op surfaces:** `run --auto-approve` (hardcoded `true`, flag ignored), `run buildRunTask` (`@deprecated`, no caller), `serve EXTENDED_MIME_TYPES` (exported, never passed to server), `serve --dev-port` (feeds only a log line; no proxy wired), `skill-marketplace` registry cache (`getCached`/`setCache` never called by `search`).
- **install/update divergence in `skill.ts`:** update drops Zod validation + activation-rule regen and uses the old 30s clone timeout — a lighter re-impl of install that silently lost safety steps.
- **Dead-test exposure:** the security-critical `skill publish` pipeline is fully `describe.skip`'d since Sprint 150; multiple suites assert on production-dead exports (buildRunTask, EXTENDED_MIME_TYPES, the registry cache, retro-parser/formatter), inflating coverage with no runtime guarantee.
- **i18n drift:** `review.ts`, `run.ts`, `skill.ts`, `skill-marketplace.ts` and the `retro` label system hardcode English instead of `getMessage`, against CLAUDE.md i18n-first.
- Clean: `set-directives.ts` (full i18n + exit codes); `recover.ts` is structurally sound (only duplicate-threshold nits).
