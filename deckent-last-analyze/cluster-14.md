## Summary
This cluster is dominated by **build-test-but-never-wire** debt: four planner exports (`auditPlanGroundTruth`, `validateGoCriteriaScope`, `callZeroConfigPlanner`, `buildZeroConfigFallbackPlan`), the entire `post-sprint-smoke` phase, `PromotionPipeline.runIdentityMutation`, and the `prompt-evolution` rollback path are all defined, tested, and (some) re-exported through barrels, yet have zero production call sites — so several advertised guarantees (plan-time ground-truth audit, scope-sufficiency, verify-task race fix, identity mutation, prompt evolution) are runtime-invisible. The most actionable defect is `promotion-pipeline.ts:504` using CommonJS `require('fs')` inside an ESM module, which throws and is swallowed, silently breaking sprint-scoped agent/skill promotion. Where code IS reachable, soft-guarantee patterns recur: a no-op smoke runner that passes everything, hardcoded-0 process metrics, dormant promotion/demotion knobs (`minSprints`, `unusedSprints`), and a silent-null planner fallback that contradicts the sibling honest-fallback contract. Net: deckent's self-orchestration advertises more verification and learning machinery than it actually executes.
