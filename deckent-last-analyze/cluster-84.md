## Summary
This cluster splits cleanly into **three dead modules**, a **broken-wire pair**, and a **TUI surface that renders placeholders**. Three whole files are test-only surface with zero production callers: `terminal-utils.ts` (all 5 exports imported only by its own test; `dashboard.ts` even rolled its OWN local `getTerminalWidth` rather than import this one), `theme.ts` (a third, unused ANSI-color implementation behind `ansi.ts`/`output.ts`), and `repl/ink-probe.tsx` (the Sprint-224 Ink-migration de-risk probe, orphaned after the migration shipped). `worker-status.ts` is also production-dead (`WorkerStatusTracker` instantiated only in tests) AND ships a `statusToProgress` map that disagrees with the live `worker.ts:calculateProgress` on every shared status — a divergence that would only have surfaced if anything actually used it. The **broken-wire pair** is the external-MCP-client surface: `mcp-bridge.ts`'s `initReplMcpBridge` is documented as "the composition root the REPL calls", but it has zero callers — the live `/mcp` path in `chat-native.ts:619` rebuilds the broker+registry+bridge inline, so both the composition root and the `mcp_client_enabled` default-OFF flag it enforces are dead (production gates on server-presence instead). The **placeholder TUI** is `status --follow`: its Elapsed/Hard-cap line reads `sprint_started_at` + `sprint_hard_timeout`, neither of which is ever WRITTEN anywhere in `src/`, so the line is permanently `⏱ Elapsed: ? · Hard cap: —`; and the entire partial-redraw optimization (`partialRedraw`/`resetRedrawState`, built + tested as a "no flicker / only changed lines" polish feature) is bypassed by the live full-screen `redraw`. A coherent REPL-input defect rounds it out: `inkToKey` claims to handle Home/End but checks `key.home`/`key.end` flags Ink never sets (and never inspects `input` for the escape sequences as its own comment says to), so Home/End silently do nothing on the live REPL and the matching `line-edit.ts` reducer cases are unreachable. Highest-value fixes: delete-or-wire the three dead helpers (`terminal-utils`, `theme`, `ink-probe`) and `WorkerStatusTracker`; collapse the duplicate MCP-bridge composition onto `initReplMcpBridge` (or delete it and honour `mcp_client_enabled`); populate `sprint_started_at`/`sprint_hard_timeout` (or stop advertising Elapsed/Hard-cap); and implement Home/End from the raw escape sequence so the advertised line-editing works.
