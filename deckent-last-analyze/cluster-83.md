### root-cause (silent-fallback / trust-without-verify / hardcoded-0-metric)
- [root-cause|high] Corrupt review state silently reset to empty (data loss) — `src/cli/helpers/review-actions.ts:88` — `try { const raw = fs.readFileSync(filePath, 'utf-8'); return JSON.parse(raw) as ReviewState; } catch { return { sprintId, entries: [], ... }; }` — both an IO error and a JSON-corruption error collapse to "fresh empty state"; a damaged `review-<sprintId>.json` silently discards every prior approve/reject decision instead of surfacing the corruption.
- [root-cause|medium] Persisted JSON cast without schema validation (trust-without-verify) — `src/cli/helpers/progress-persistence.ts:72` (`return JSON.parse(raw) as ProgressState;`), `src/cli/helpers/review-actions.ts:90` (`as ReviewState`), `src/cli/helpers/selective-retry.ts:39` (`as RetryQueue`) — disk JSON is blind-cast to the typed shape with no field check; a structurally-valid-but-wrong JSON (missing `entries`/`taskIds`/`updatedAt`) is trusted, propagating `undefined` into downstream `.find`/`.length`/`new Date(...)`.

## Summary
Cluster cli#9 is dominated by a **large unwired subsystem**: 9 helper classes (review-actions, review-summary, selective-retry, progress, progress-persistence, queue-display, recommendations, sprint-comparison, and the plain-text sprint-summary class) have **zero `src/**` callers** — only their own unit tests reference them, producing high false-coverage confidence (dead-test|high). Live wiring is limited to `process.ts` (`resolveProjectRoot`/`handleCliError`), `prompt.ts` (init/plan), `splash.ts` (init/index/sprint-phases), `process-runtime.ts` (`buildProcessController` → process command/endpoint/MCP), and `sprint-summary-rich.ts` (`formatRichSprintSummary` → sprint-finalizer). Key inconsistencies: two divergent same-name `ProgressState` interfaces, a `RichSprintSummary` class-vs-interface collision, an ignored `_positiveIsGood` parameter, and a non-i18n `formatDuration` duplicated ≥6× against the lang-aware canonical. Root-cause risks center on unvalidated persisted-JSON casts + catch-all silent fallbacks (worst: corrupt review state silently wiped) and `?? 0` coverage that renders missing data as a real `0.0%`. No source modified (read-only audit).
