## Summary
This cluster is the autonomous-v2 goal→backlog→mission spine and is broadly wired (planner→JIT-detail→dispatcher→mission-engine all have live callers), so the issues are not dead code but **soft guarantees**: three "fail-safe" boundaries (audit write, mission delivery, planner parse) silently swallow failures with little or no observability, and the goal-loop's infinite-loop guard ships an unsafe `?? Infinity` default that only the current sole caller happens to override. The pattern deckent reveals about itself here is that its autonomy safety/integrity rails are convention-enforced at the call-site rather than guaranteed at the seam — an audit gap, an undelivered mission, or a dropped planner item all currently pass silently. Secondary hygiene: one dormant UI step (`picked`), two export-without-consumer helpers, and a stale i18n comment whose fallback is now dead.
