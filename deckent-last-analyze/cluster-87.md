## Summary
24 findings across the 18-file `dashboard#1` cluster (unwired 6, dormant 3, inconsistent 4, dead-test 7, root-cause 4). **Largest signal — unwired:** the entire `src/dashboard/analytics/` layer (4 classes: `AnalyticsData`, `AgentComparisonData`, `SkillHeatmapData`, `SuccessChartData`) plus the `AppShell` shell — and `AuthStatus`, whose only consumer is that dead shell — are built and tested but have **zero runtime callers** (grep-verified; only `tests/` + `docs/audits/` reference them) — a test-only data/UI layer with no rendered surface. **Dead-test:** 6 of the 8 co-located tests are source-inspection (`readFileSync` + `.toContain` of class names / route literals / CSS tokens / magic `500`) — they assert that implementation *strings* exist, not that behavior is correct (terminal-no-overlap and live-merge are the clearest tautologies). **Dormant:** `filterByDateRange` is unreachable for real dates (1970-only guard), `ActivityFeed.prevDoneRef` is write-only, and `turkishStringPatterns` is an unused regex array. **Inconsistent:** stale "this test isn't run" comments contradict the active `vitest.dashboard.config.ts` include; a duplicate orphaned `src/dashboard/vitest.config.ts` diverges; `DebtTable` parses deprecated ADR-009 markdown instead of the DB SSOT. **Root-cause:** Coverage `NaN%`→0 silent fallback, `DebtTable` empty-cell column misalignment, tech-debt-as-success inflation (×3), and AgentDetail's swallowed fetch errors. Two candidate findings were rejected by verification: `.brain/sprints/` does exist (loadSprintData path is valid) and Duration parses correctly from the real `…ms` format. No source files modified.
