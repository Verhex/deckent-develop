- [root-cause|critical] `checkWorkerAuthority` advisory-soft: `return true` on violation — `src/agents/worker.ts:617` — `if (!result.allowed) { console.warn('[deckent] [ADR-037 soft] Worker ...'); if (sprintId) { emitAuthorityViolation(...); } return true; }` — Violation detected, warning emitted, but `true` returned unconditionally. The ADR-037 V1.0 "advisory/soft" design is the root; the boolean return is a permanent lie that prevents callers from acting on authority failures.

- [root-cause|high] `authHealthCheck` uses `spawnSync` — `src/agents/worker.ts:696` — `const r = spawnSync('claude', ['--version'], { encoding: 'utf-8', timeout: 5_000, shell: process.platform === 'win32' })` — ADR-087 (Async I/O & Test Hermeticity) and karpathy-discipline explicitly prohibit `spawnSync`: "No spawnSync for subprocesses — use async `spawn` (child_process) so the worker does not freeze waiting for a subprocess. spawnSync blocks the event loop and causes CI timeouts." This is the only remaining `spawnSync` call in `src/agents/worker.ts` (line 14 imports it solely for this).

- [root-cause|medium] Silent fallback in `isWithinScope` on non-ELOOP errors — `src/agents/worker.ts:556-562` — `} catch (err: unknown) { if (err instanceof Error && 'code' in err) { const code = (err as NodeJS.ErrnoException).code; if (code === 'ELOOP') return false; } }` — When `realpathSync` throws any error other than `ELOOP` (e.g., `ENOENT` for non-existent file, `EACCES` for permission denial), the error is silently swallowed. `resolvedFile` remains as the unresolved `normalizedFile` and proceeds to scope directory/filesWrite checks. - [root-cause|medium] Honest-gate false-positive for read-only/audit tasks — `src/agents/worker.ts:410-415` — `const linesAdded = result.linesAdded ?? 0; ... const looksLikeStub = (result.selfAssessment === 'DONE' && linesAdded === 0 && !testsPassed)` — The `?? 0` default means any result without `linesAdded` field is treated as 0. A legitimate read-only audit task (selfAssessment=DONE, linesAdded=0, testsPassed=false) matches the stub pattern and gets downgraded to NO_GO.
