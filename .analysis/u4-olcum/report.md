## Methodology

- Corpus: 8 real historical sprint tasks (title/description/scope/goNogo/assignedAgent/assignedSkills/routingMeta copied verbatim from real `.brain/archive/sprints/**/task-*.json` records), spanning distinct primary intents:
  - bugfix: 1
  - config: 1
  - design: 1
  - devops: 3
  - implementation: 1
  - security: 1
- ADRs: live .brain/memory.db (47 accepted ADRs) (real `getByType('adr')` call, same as production `task-builder.ts` `buildWorkerPrompt`).
- Agent personas: real `src/core/builtins/agents/<id>/PROMPT.md` files.
- Skills: real `src/core/builtins/skills/<name>/SKILL.md` files; 1 assigned skill(s) skipped — no static SKILL.md file (dynamically-resolved at runtime, not measurable here): project-conventions.
- Segment bytes = UTF-8 byte length of each `PromptSegment.content`, bucketed by `kind`: `persona`→persona, `adr`→adr, `skills`→skills, `task`→task-core, everything else (worker-contract, verify-steps, verify-precedence, npm-advisory, karpathy, what-to-do, heartbeat, result-contract, smoke, scope, goNogo, deps, shared, handoff, comms)→rest.
- Both `persona_render` modes (`full`, `guidance`) composed for every fixture task with an otherwise byte-identical `SprintContext` (same agent prompt, same skills, same ADRs, same effort).

## Findings

- **Remaining gap**: the measured ADR segment average in `guidance` mode is 4,035 bytes (3.94KB), which exceeds the 1KB threshold. `guidance` mode (task 443-003) only condenses the AGENT PERSONA block — the ADR block is rendered independently (`buildAdrBlock`, unaffected by `personaRenderMode`) and still carries the operative-ADR full body (PCOMP-W4 tiering: only the non-governing ADRs are condensed; the governing/explicit-ref ADR keeps its full Decision body). This is a genuine remaining cost surface, distinct from the persona-render work this task measures — **not patched here** per this task's scope.
- Persona segment delta (guidance vs full) averages -83.0% — this is the primary effect task 443-003's guidance-mode render is expected to produce.
- 1 assigned skill(s) have no static `SKILL.md` file and were excluded from every measured prompt (both modes, symmetric — does not bias the delta): project-conventions.
