# Nervous System Alerts

The Deckent Nervous System proactively monitors the sprint for critical issues and surfaces alerts that require attention.

-   **`deckent nervous status`**: Check the current status of all active alerts.
-   **`deckent nervous subscribe`**: Subscribe to receive real-time alerts.
-   **`deckent nervous accept <alert-id>`**: Acknowledge and accept an alert, indicating you will handle it.
-   **`deckent nervous reject <alert-id>`**: Dismiss an alert if it's not relevant or has been resolved externally.

These commands allow you to manage and respond to the proactive insights from the Nervous System.
