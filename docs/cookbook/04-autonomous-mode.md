# Cookbook: Autonomous Mode

Deckent's autonomous mode allows the engine to continuously manage a backlog of tasks. This backlog can include recurring tasks, one-off tasks, and reactive operations.

Autonomous mode operates under a system of approval, policy, and risk gates. This means that certain operations, particularly those identified as risk-tagged, will be parked for your explicit approval before they are executed. This mechanism ensures that you maintain control over critical actions while benefiting from continuous automation.

To learn more about enabling and configuring autonomous mode, consult the `deckent help` command for the most current and detailed instructions.
