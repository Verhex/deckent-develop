## Acceptance rule

A source export or test import is not production wiring. This audit identifies the production command consumer separately from integration proof. Any authority lacking either is **BLOCKS_CURRENT_DONE**.

## Conclusion

The integration test imports no adoption or receipt-store function. It compiles current source and drives emitted `cli/entry.js` in independent subprocesses (`tests/cli/provider-observation-adoption-receipt.integration.test.ts:168-183,196-268`). The production chain is:

`compiled CLI entry → registered adopt action → render → defaultAdoption → inspect/plan → publish/build/verify → exact read(fresh) → verifyFresh → redacted projection`.

Every mapped authority has a real production consumer and real-entry end-to-end proof. No test-only import is counted as wiring, and no unresolved **BLOCKS_CURRENT_DONE** gap remains. Verdict: **GO**.
