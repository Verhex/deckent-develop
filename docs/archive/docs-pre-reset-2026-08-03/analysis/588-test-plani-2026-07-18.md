# 588 F0+F1 Test-Planı — Alperen el-testi (2026-07-18)

> **Nasıl kullanılır:** Sırayla git; her adımda **Beklenen**'i gördün mü işaretle. Sapma = chat'e
> tek satır: `T<numara> düştü: <ne gördün>` — CC anında günlüğe işler + teşhis eder. Hepsi
> geçtiyse `test tamam` yaz; feedback'lerinle kapatırız. *(Rapor-biçimi örn: "T3 ok, T5 düştü: kartlar boş")*

## Kurulum (bir kez)
- **K1.** Desktop-penceresi açık değilse: `! npm run dev:desktop`
- **K2.** **Disconnect → Connect** (⚠️ zorunlu: bugünkü yeni endpoint'ler — `/api/sprint/*`, `/api/git/*` — taze daemon ister; eski daemon'da Köprü/Changes "load error" verir)

## A · Kabuk + yerleşim (F0d + P6)
- **T1.** Sol-ray görünümü: **SEYİR** (Köprü · Koşular · Approvals) ve **ÇALIŞMA** (Chat · Engine Room · Changes) grup-başlıklarıyla; menü SOLDA. Alt-köşede `Connected: …`
- **T2.** Vardiya değiştir (bağlantı-ekranındaki seçici ya da mevcut yerinden): tüm yüzeyler + Makine-Dairesi terminal-renkleri birlikte döner

## B · «Köprü» (F1 — ana test)
- **T3.** Köprü sekmesi, sprint YOKKEN: dürüst boş-mesaj ("Canlı sprint yok — …emir verin") + altta mevcut Rota/Emir-satırı. *Load-error YOK.*
- **T4.** **Canlı-sprint testi:** ayrı terminalden küçük bir gerçek koşu başlat (örn. REPL'den bir `deckent do "<küçük iş>"` ya da hazır bir flow'u `runs <n> --start`) → Köprü'de ~2sn içinde: faz-şeridi aktif-faz vurgulu + **worker-kartları belirir** (task-id · başlık · ajan/model · durum)
- **T5.** Kartlarda **canlı nabız**: son-eylem satırı değişiyor, yaş-sayacı (örn `7sn`) akıyor, dosya-sayacı artıyor
- **T6.** "Hareketteki dosyalar" paneli: worker'ların yazma-kapsamları listeli; (varsa) aynı dosyada iki worker → kırmızı
- **T7.** Bir karta TIKLA → **Worker-Penceresi** açılır

## C · Worker-Penceresi (F1)
- **T8.** Başlık: task-id + hb-durumu + yaş; **Canlı**-sekmesinde satırlar AKIYOR (insan-okur `[tip] özet` biçimi; N5-akışının görsel-kanıtı). Log yoksa dürüst "Henüz log yok…"
- **T9.** Sekmeler ok-tuşuyla gezilir (react-aria): **Görev** (hedef + GO-ölçütleri + yazma-kapsamı) · **Plan** (.plan metni ya da dürüst "yazılmadı") · **Sonuç** (koşu bitince öz-değerlendirme)
- **T10.** `← Köprü` ile dön; koşu BİTİNCE aynı pencere arşiv-görev olarak hâlâ açılıyor (Sonuç dolu)

## D · Koşular-detayı (F0b)
- **T11.** Koşular: satıra tıkla → altta detay (Hedef · Revizyon · durum-rozeti + Plan-önizleme + Changes-diff'i); ikinci tık kapatır

## E · «Changes» (F0a — incele→mühürle)
- **T12.** Kirli-ağaçta: dosya-listesi (+ekleme/−silme) + **düzenlenebilir mesaj** (önerilen dolu) + açık diff
- **T13.** Mesajı değiştir → **Commit** → yeşil `Committed <sha>.` satırı; liste temizlenir ("Working tree clean"); terminalden `git log -1` aynı mesajı gösterir
- **T14.** Temiz-ağaçta: dürüst "Working tree clean" (ölü-düğme yok)

## F · «Telsiz» kalıcılığı (F0c) + P4-tekrarı
- **T15.** Telsiz'de 2-3 mesajlaş → **uygulamayı tamamen kapat-aç** → konuşma YERİNDE (yarım-kalan stream-satırı dürüstçe düşmüş olabilir)
- **T16.** Sekmeler-arası gez (Telsiz↔Engine-Room↔Köprü): her şey kaldığı yerden

## G · Hızlı-regresyon (bugünkü fix'ler)
- **T17.** Engine Room: yeni shell-oturumu + `ls` → çıktı ✓ (P5-fix'i ayakta)
- **T18.** Approvals/Koşular açılışında CORS-hatasız veri ✓ (P2-fix'i)
