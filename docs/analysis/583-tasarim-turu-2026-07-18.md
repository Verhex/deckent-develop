## 2 · Öneri-paketi

### DT-1 · «Telsiz» — Desktop-Chat gerçek olur (P0, vizyon-merkezi)
**İş:** Boş-durum telsiz-ekranı gerçek telsize dönüşür: operatör deckent'le Desktop'tan konuşur.
**Neden şimdi:** Daemon-kontrat HAZIR (`POST /api/chat` + `GET /api/chat/stream` SSE, provider-adapter'lı,
7 test-dosyalı) — PTY-panelde olduğu gibi mevcut-kontrata bağlanma işi; sıfır yeni sunucu-altyapı.
**Tasarım:**
- Köprüüstü dili: **«Telsiz»** (watch-radio — boş-durumun kendi metaforu zaten bu). Emir-satırı
  (Console, iş-emri→RunFlow) ile ayrışır: Telsiz = sohbet/soru-cevap/yönlendirme; Emir = iş başlatma.
  Telsiz'den gelen "işe dönüşsün" anları Console'a el verir (v1: yönlendirme-metni; derin-entegrasyon sonra).
- Akış: mesaj-listesi (operatör ↔ deckent, vardiya-token'lı balonsuz sade satır-blokları — aşırı-temalaştırma
  yasak guardrail'i), SSE-stream yazımı (token-akışı geldiğine göre progressive-render), tek-satır girdi +
  Enter; hata/adapter-yok durumları dürüst-bant.
- **Gate-gerçeği (SURF-7 ratchet):** `/api/chat*` control-mutations-gate kapsamında (default-OFF). Çözüm
  N5-simetrisi: **desktop-lifecycle KENDİ spawn ettiği daemon'a `DECKENT_CONTROL_MUTATIONS=1` env-twin'i
  verir** (kendi-spawn'ladığın yerel daemon = senin kontrol-düzlemin; global default-OFF değişmez).
  Adopt-edilen daemon'da flag neyse o — kapalıysa Telsiz dürüst ön-koşul-bandı gösterir (decide_off deseni).
- SSE auth: EventSource header taşıyamaz → SURF-2 query-token yolu (`?token=`); allowlist-genişletme
  gerekiyorsa ratchet-testleriyle pinli yapılır.

### DT-2 · A11y onur-borcu kapanır (P0)
Kilitli `react-aria-components` gerçekten giyilir — **cerrahi kapsam:** yeni-yazılan Telsiz (TextField/Button)
+ EngineRoom sekmeleri (`Tabs` — klavyeli roving-tabindex bedava) + odak-halkası `focus-ring` token'ına bağlanır.
Shell'in kalan organlarına retrofit YOK (çalışan yapıyı bozmamak; ihtiyaç KABUL pürüz-avında born'lanır).

### DT-3 · Rota-hover mevki-kaydı (P1 — D4-0 imzasının tamamlanışı)
Course-fix noktasına hover/focus → o mevkinin olay-kaydı (tip + humanize-zaman; native `title` +
`aria-label`, motion'sız). Küçük, imzayı söz-verildiği hâle getirir.

### DT-4 · Süzülme-geçişleri (P1)
Görünüm-değişimi + panel-belirmeleri ~240ms ease-out ("yanaşır, belirmez"); `prefers-reduced-motion`
hepsini kapatır. Salt-CSS.

### DT-5 · Terminal tasarım-dili SSOT'u (P1 — doküman)
`docs/reference/terminal-design-language.md`: lowercase-vocabulary · kart-idyomu (onay/inbox/preview) ·
ortak-kelime kuralı (`tui.inbox_state_*`) · protokol-vs-i18n çizgisi (`[deckent]`/`[mcp-error]` EN-kanonik) ·
sembol-dili (⚡Live, durum-işaretleri) · Köprüüstü-Desktop ile ilişki (aynı kelime-hazinesi, farklı ton).
KABUL pürüzleri bu referansa karşı değerlendirilir.

### Kayıt — bilinçli KABUL-SONRASI (tur-kararı, şimdi iş değil)
Desktop config-editörü + entegrasyon-yönetimi (SURF-7-vizyonunun kalanı, 584-587 satırlarıyla ilişkili) ·
durable chat-history · Rota zoom/geçmiş-gezinme · Telsiz→Emir derin-entegrasyonu.
