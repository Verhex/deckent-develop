# Feature catalog

## Scope, evidence, and status

This catalog joins three views that must not be confused: the product capability a user can select, the current repository implementation, and the usage heuristic recorded by the feature manifest. The manifest is generated from a curated list plus basename/import counting over the last ten sprints; `active`, `lightly_used`, and `dormant` therefore describe observed code use, not a release guarantee. Status meanings:

- `✅ live`: production entry and consumer wiring are present; the row does not imply that every environment was exercised in this documentation audit.
- `⚠️ partial`: a named flag, integration, proof, parity, or reliability constraint remains.
- `🔜 roadmap`: the repository contains a contract or isolated component but no production closure is claimed.
