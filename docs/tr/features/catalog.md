# Özellik kataloğu

## Kapsam, kanıt ve durum

Bu katalog karıştırılmaması gereken üç görünümü birleştirir: kullanıcının seçebileceği product capability, bugünkü repository implementasyonu ve feature manifestin kaydettiği kullanım heuristic'i. Manifest, curated bir liste ile son on sprintteki basename/import sayımından üretilir; bu nedenle `active`, `lightly_used` ve `dormant` sınıfları gözlenen kod kullanımını anlatır, release garantisi vermez. [Kanıt: `.deckent/settings/features-manifest.json:2-24`]

Görev prompt'u `.deckent/features-manifest.json` yolunu verdi; bu yol yoktur. Repository dosyası `.deckent/settings/features-manifest.json` konumundadır. Bu katalog eldeki tek envanteri kullanırken authority belirsizliği OQ-19'da `HOLD` olarak izlenir. [Kanıt: `docs/analysis/OPEN-QUESTIONS-2026-08.md`, OQ-19]

Durumların anlamı:

- `✅ canlı`: production entry ve consumer wiring vardır; satır, bu dokümantasyon audit'inde her environment'ın çalıştırıldığı anlamına gelmez.
- `⚠️ kısmi`: adı verilen flag, integration, proof, parity veya reliability kısıtı vardır.
- `🔜 roadmap`: repository'de contract veya izole component vardır; production closure iddia edilmez.

Aşağıdaki tüm komutlar, 212 çağrılık binary audit'inde `--help` çağrısı exit 0 olan gerçek registered path'lerdir. Bu dokümantasyon çalışmasında state-changing execution yasaktı; etkilenen satırlar bunu açıkça söyler. [Kanıt: gerçek-binary recursive help audit'i, 2026-08-01; OQ-20]
